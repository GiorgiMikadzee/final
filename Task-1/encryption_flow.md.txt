This project demonstrates a basic hybrid encryption scheme combining RSA and AES.

User A generates RSA keys and shares the public key. 
User B encrypts the message "Bilbo Baggins had the Ring" using a random AES-256 key, and encrypts that AES key with RSA. 
The encrypted AES key and AES-encrypted message are saved.

User A then uses their RSA private key to decrypt the AES key and recover the original message.

Files included:

Final_Task_1_Mikadze.py — Python code

message.txt — original message

encrypted_message.bin — AES encrypted message with IV

aes_key_encrypted.bin — RSA-encrypted AES key

decrypted_message.txt — recovered message

This simple system models how secure communication apps protect messages during transmission.
